# Code of Conduct

ny-pi adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of
conduct. The summary below does not replace that text.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body
size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Standards

Expected: kindness and respect, constructive feedback given and received gracefully, owning mistakes, and focusing on
what is best for the project.

Not acceptable: sexualized language or imagery, trolling, insulting or derogatory comments, personal or political
attacks, public or private harassment, publishing others' private information without permission, and other conduct
that would reasonably be considered inappropriate in a professional setting.

## Scope

This applies in the repository (issues, pull requests, discussions, reviews) and wherever someone represents the
project in public.

## Reporting

Report unacceptable behavior privately: open a private report through GitHub to the
repository owner (**Security > Report a vulnerability**, stating that it is a conduct report, with no vulnerability
details), or flag the post in
[Discussions](../../discussions) so it can be moderated. Reports are handled
confidentially, and no one is retaliated against for reporting in good faith.

## Enforcement

The maintainer may edit or remove comments, close or lock threads, and temporarily or permanently ban a participant.
Responses follow the Contributor Covenant enforcement guidelines: correction, warning, temporary ban, permanent ban.
